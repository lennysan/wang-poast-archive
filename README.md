# The Wang Poast Archive

An archive of Alexandr Wang's (@alexandr_wang) real tweets about Muse, with their actual photos and videos. Tweet data lives in `data.js` (fetched from X on Oct 8, 2026). No-build vanilla HTML/CSS/JS.

```bash
cd alex-wang-poasts
python3 -m http.server 8744 --bind 127.0.0.1
```

Then open http://127.0.0.1:8744/ in your browser.

Live at https://lennysan.github.io/wang-poast-archive/
